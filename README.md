# -局域网点歌系统
-应用场景：办公室内一个音响
-解决痛点：每个人都有自己想听的歌单  
-仅Windows  需要安装VLC播放器（源码里是安装在默认文件夹，C盘或者D盘）,下载地址：https://get.videolan.org/vlc/3.0.23/win64/vlc-3.0.23-win64.exe  
-本程序基于Python flask生成的局域网点歌系统  
-Python版本 3.10.4  
-启动程序 python main.py  
-需要安装的依赖在requirements.txt  
-需要在main.py第50行QQ_API_KEY = "填入你的API key"  
-申请地址https://api.tjit.net/user/key（感谢明伟数据免费支持） #这个是导入QQ音乐歌单必备（可选）  
-音乐解析提供https://api.xcvts.cn/api/music/bdyy（感谢小尘api免费使用）
