# -局域网点歌系统
应用场景：办公室内一个音响
解决痛点：每个人都有自己想听的歌单

本程序基于Python flask生成的局域网点歌系统
Python版本 3.10.4
启动程序 python main.py
需要安装的依赖在requirements.txt
